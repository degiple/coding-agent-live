# アプリごとの基本仕様（当日の15分枠で作れる最小の範囲）

依頼文の Goal と Context に写す元ネタです。見た目は書きません（投票で後から決めます）。数値のうち「暫定」は、この枠で作る前提で仮に置いた値（過去の記録で未確定のもの、モックの仮の値、この枠で新しく設計したものを含む）で、実装者が変えてよいものです。「過去の記録」は、事前に作った試作の仕様です。

## みんなでクリック

- 画面: チェックボックスの格子を1000マス（暫定。過去の記録では未確定の既定値）並べる。携帯の幅でも押し分けられる大きさにする。
- 操作: 1マスを押すと、全員の画面で ON と OFF が切り替わる。他人が付けたチェックも外せる。
- 保存: 各マスの ON/OFF を `ctx.storage` に保存する。再起動しても残る。
- 制限: 同じ端末からの連続クリックは、1秒（暫定）あいだをあける。サーバー側でマス番号の範囲外を拒否する。
- 作らないもの: 管理用の画面、リセット機能。

## ワードクラウド

- 画面: 入力欄と送信ボタン。送られた単語が、回数に応じた大きさで並ぶ（16px〜64pxで線形、過去の記録）。上部にお題（ダミーの文言でよい）を固定表示する。
- 操作: 同じ単語が送られるたびに回数が増え、文字が大きくなる。表示は最大50語。超えたら回数の少ない語から外れる（過去の記録）。
- 保存: 単語と回数を `ctx.storage` に保存する。
- 制限: 1回の送信は14文字まで。前後と途中の空白を除く（過去の記録）。送信の間隔は3秒（暫定）。不適切語の除外リストは作らない。荒らしへの備えは、文字数と送信間隔の制限、運営による削除の手段（アプリの外で用意する）で行う。送られた文字はHTMLとして解釈しない。
- 作らないもの: 管理用の入口（閲覧専用の切り替え、全体の削除など）。

## 共同ドット絵

基本仕様。過去の記録どおりの内容だけを書き、工夫は足さない。

- 画面: 60列×40行（2400マス）のキャンバスと、16色のパレット。色は #FFFFFF, #E4E4E4, #888888, #222222, #FFA7D1, #E50000, #E59500, #A06A42, #E5D900, #94E044, #02BE01, #00D3DD, #0083C7, #0000EA, #CF6EE4, #820080（過去の記録）。
- 操作: パレットで色を選び、マスを押すとその色が置かれる。全員の画面に反映される。
- 保存: 各マスの色を `ctx.storage` に保存する。
- 制限: 1人あたり3秒に1回まで（暫定。過去の記録では仮の値）。サーバー側でパレット外の色と範囲外のマス番号を拒否する。
- 確認: 携帯の幅でマスを押し分けられるか（過去の記録では未検証）。
- 作らないもの: 管理用の画面、リセット機能。

## コメント流し

- 画面: 入力欄と送信ボタン。送られたコメントが、画面を右から左へ流れる。
- 操作: 同時に流れるのは30件まで（過去の記録）。速度は200px/秒（暫定。モックの仮の値）を目安にする。レーンの数は実装者が決める。
- 保存: 履歴は保存しない。流れて消えるものなので、再起動で消えてよい。新しく開いた画面には、直近のコメントだけ返す。「直近」は最大200件（暫定。過去の記録の待機列上限200件を参考にした値）で、超えたら古いものから捨てる。
- 更新の仕組み（暫定。過去の記録に無く、この枠で新しく設計した仕組み）: サーバーは直近のコメントに連番を付けて持ち、画面は最後に受け取った連番より後のものを2秒ごとに取る（同じコメントを二度流さないため）。連番はメモリ上だけで持つと、退避や再公開で0に戻り、画面が新着を受け取れなくなる。そこでサーバーは起動ごとの識別子も返し、画面は識別子が変わったら、持っている連番を捨てて全件を取り直す。取り直した全件は流さず、連番だけを更新して、以降の新着を流す。
- 制限: 1回の送信は40文字まで（過去の記録）。送信の間隔は3秒（暫定）。不適切語の除外リストは作らない。荒らしへの備えは、文字数と送信間隔の制限、運営による削除の手段（アプリの外で用意する）で行う。送られた文字はHTMLとして解釈しない。
- 作らないもの: 管理用の画面、リセット機能。
