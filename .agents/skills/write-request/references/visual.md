# 見た目の指示（場面Bで依頼文に写す）

場面Bで `docs/request.md` の「見た目の仕上げ」の節に写す指示です。実装者は依頼文だけを読むので、スキル側の参照に頼らず、下の本文をそのまま写します。数値のうち「暫定」は実測していない値で、実装者が変えてよいものです。

## 写す本文

```markdown
- スキル frontend-design を併用する。デザイン案は10行以内にし、確認を待たずに進める。スクリーンショットでの見直しは1回まで。
- スキルの控えめ寄りの指示（演出を1か所に絞る、動きを抑える など）と、この節の指定が食い違うときは、この節を優先する。
- 演出は派手でよい。
- 演出は絵文字・CSS・短い JavaScript を基本にする。送信時の反応が花火のときだけ、`public/vendor/confetti.browser.js`（canvas-confetti 1.9.4）を使う。花火以外が選ばれたときは、花火もライブラリも足さない。ほかのライブラリは足さない。ビルドしない。
- 送信時の反応が花火のときだけ: canvas-confetti は読み込めなくても送信が壊れないよう、`typeof confetti === 'function'` で守る。`disableForReducedMotion: true` を付ける。
- 送信時の反応が花火のときだけ: `ticks` は120以下にする。長さはフレーム数で決まり、60Hzの画面で約2秒、144Hzの画面でも約2.5秒（既定の `ticks` 200は60Hzで約3.3秒）。
- 1回の演出は3秒以内、同時に出す粒は100個まで（暫定）。
- 書体: テーマに合わせて選ぶ。Google Fonts から1つまで。読めなくても読める代替フォントを指定する。日本語が崩れないこと。
- 送られた文字は `textContent` で入れる。口調のひと言は固定の文言から選び、送られた文字を混ぜない。
- 幅360pxの画面で崩れない。押せる部分は44px以上。`prefers-reduced-motion` のときは演出を止める。
- 放射状の光線の背景は使わない。
```

## 使い方

- 場面Bの「Constraints に追記する」で、追記する節の中の「送信時の反応」の行と「見た目だけを変える」の行のあいだに、上の本文の各行をそのまま写す。節の他の行（テーマ・キャラクター・送信時の反応・見た目だけを変える・「仕上げのあとも、Done when の確認がすべて通ること」の行・計画）は、SKILL.md の雛形どおり。
- どの行も、テーマを問わず外さない（外す判断を増やさないため）。「送信時の反応が花火のときだけ」を冠した行は、送信時の反応が花火のときに限って効く条件つきの行で、行ごと写す。花火以外が選ばれたときは、その行が効かないだけで、行を外す判断ではない。
